Log Analyzer
============

A small Python project that reads a log file, counts log levels (ERROR, WARNING, INFO), finds the top repeated messages, and generates a report.

Project structure:
- log_analyzer/
  - __init__.py
  - analyzer.py
  - sample_log.log
- tests/
  - test_log_analyzer.py
- log_report.txt (generated by running the analysis)

Usage:
- Run tests: python -m unittest discover -v
- To analyze a log file and generate a report:

  python - <<'PY'
  from log_analyzer import LogAnalyzer
  la = LogAnalyzer(path='log_analyzer/sample_log.log')
  la.generate_report('log_report.txt')
  print('Report written to log_report.txt')
  PY

# File Analyzer

A lightweight Python utility to read a text file and print a concise summary of its contents.

## What the project does

- Reads a text file
- Counts lines, words, and characters
- Prints a clean summary

## How to run it

- Prerequisites: Python 3.x
- Run:
  - python3 file_analyzer.py <path/to/textfile>

## Example usage

$ python3 file_analyzer.py /home/shukla_deepak77/.openclaw/workspace/file_analyzer/sample.txt

## Sample output

File: /home/shukla_deepak77/.openclaw/workspace/file_analyzer/sample.txt
Lines: 2
Words: 7
Characters: 35

Note: If you want to count words differently, you can adjust the analyze_file function in file_analyzer.py.
